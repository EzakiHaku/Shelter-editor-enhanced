English — About, Credits & Licenses

This is an unofficial community-modified save editor. It is not affiliated with, maintained by, or endorsed by Bethesda or the upstream project maintainers.

Project lineage and attribution

  • Original project: MobileSam / Samuel Dionne (original MIT license, copyright 2015).
  • Upstream fork: rakion99 (AGPL-3.0 fork).
  • Additional upstream credit: TheCreatorJames (named in the original fork's Extras page).
  • Historical decryptor credits: MobileSam's README refers to Xeth137; rakion99's README cites fossd.bitballoon.com.
  • Enhanced edition maintainer: EzakiHaku.

What was enhanced?

Batch dweller editing, updated navigation, structured batch workspace, bilingual equipment lists with A–Z ordering and per-session starred favorites, contextual Wasteland visibility, and a translucent UI. These changes do not transfer authorship of upstream files.

License and source

The distribution retains the fork's GNU Affero General Public License v3 (or later) and additionally includes the original MobileSam MIT notice. The supplied package contains the corresponding HTML/CSS/JavaScript source. See NOTICE.md and THIRD_PARTY_NOTICES.md for attribution and outstanding third-party checks.

The uploaded upstream HTML contained a historical Creative Commons claim and hosted-site terms of unclear scope. They are preserved in UPSTREAM_LEGACY_NOTICE.html for transparency, not used as a blanket license for all modified code.
